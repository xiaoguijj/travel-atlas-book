# Collage 自由拼贴 · 正式界面设计说明（V1-08B）

> 概念图：[`collage-ui-reference.png`](./collage-ui-reference.png)（1448 × 1086）。
> 概念图只作为设计文档存档，不参与生产构建；**禁止**把整张概念图当作网页背景或贴图使用。

## 1. 设计目标

把 V1-08A 的临时表单式编辑页替换为「真实旅行手账」式的自由拼贴桌面：

- 进入页面即是一张铺在亚麻桌面上的米色活页纸，纸面即 1200 × 1600 的拼贴画布；
- 素材、属性工具以浮层出现，不挤压纸面、不改变画布坐标；
- 视觉语言沿用项目 `voyageVintage` 主题（深青、黄铜、陶土、旧纸），与内页头部、模式选择页保持同一套语言；
- 初始纸面保持空白，概念图里的照片、文字、票根、地图均视为创作效果示例。

## 2. 信息架构

```
InnerPageLayout（现有深青地图底 + 顶部 header）
└─ BookShell toolbar（现有：城市 / 标题 / 模式切换 / 保存状态 / 素材）
   └─ CollageView（本页）
      ├─ 桌面背景（亚麻纹理、罗盘、邮戳、装订夹）
      ├─ 左侧素材工具轨（默认收起）
      │   照片 / 城市贴纸 / 通用贴纸 / 文字
      ├─ 中央单页纸（1200 × 1600 逻辑画布，3:4）
      ├─ 选中元素浮动工具条（仅选中时出现）
      └─ 右侧图层与属性轨（默认收起）
          图层顺序 / 旋转 / 缩放 / 文字格式 / 图层列表
```

## 3. 视觉基调

| Token | 值 | 用途 |
| --- | --- | --- |
| 桌面亚麻 | `#c9b48e` → `#a98f6b` 径向渐变 + 纤维噪点 | 手账桌面 |
| 纸张 | `#f8f0df` / 高光 `#fffaf0` | 拼贴纸面 |
| 纸张阴影 | `rgba(52, 32, 14, .38)` 大范围柔和投影 | 纸与桌面的层次 |
| 墨色 | `#2b2118` | 纸面/面板正文 |
| 次级墨色 | `#6d5844` | 说明文字 |
| 黄铜 | `#b08d57` | 边框、轨条、装饰线 |
| 陶土 | `#a96c50` | 选中、危险操作、强调 |
| 深青 | `#173132` | 与站内头部呼应的深色小面积 |

- 标题字体沿用 `--font-display`（Georgia / Palatino / Songti），说明文字用 `--font-ui`。
- 纸面使用 CSS 纹理（两层径向渐变 + 细噪点 + 内阴影 + 叠纸边），不使用位图背景。
- 装饰只做「桌面层」：左上角装订夹、右下角罗盘、角落低透明度邮戳，均不进入画布坐标。

## 4. 组件规格

### 4.1 左侧素材工具轨

- 桌面端：桌面左侧固定竖排卡片，宽 68px，顶部与纸张顶部对齐；四个图标按钮（照片 / 城市贴纸 / 通用贴纸 / 文字），当前项陶土色高亮 + 左侧黄铜指示条。
- 默认收起，点击展开对应浮层；再次点击同一工具或点关闭按钮收起。
- 展开的浮层锚定在工具轨右侧（宽 300px、最高 `calc(100% - 96px)` 可滚动），不改变纸张尺寸与坐标。
- 浮层内容：
  - 照片：2 列照片网格，点缩略图直接插入纸面；
  - 城市贴纸 / 通用贴纸：3 列贴纸网格，点缩略图直接插入；
  - 文字：添加文字按钮与排版提示；
  - 三个素材面板底部都有「打开素材册」，复用现有 `AssetPanel`（上传、完整素材库），不另建素材系统。

### 4.2 中央纸面

- 单页活页纸，逻辑画布固定 1200 × 1600，显示尺寸按宽度等比缩放，纸张宽高比 3:4。
- 纸面尺寸同时受视口宽高约束，目标是在 1440 × 900 及以上桌面尽量接近概念图（可视纸宽 560–680px），并保证不出现整页纵向滚动。
- 纸面本身不画网格、不预置内容；`CollageStage` 的 Konva 画布铺满纸面，坐标映射不变。

### 4.3 浮动工具条

- 选中元素后出现在纸面上方居中，`role="toolbar"`，`aria-label="选中元素操作"`。
- 内容：置顶 / 上移 / 下移 / 置底 / 编辑文字（仅文字）/ 适应画布（仅超出纸面时）/ 删除 / 图层与属性。
- 取消选中（点纸面空白或删除）后立即隐藏。
- 桌面端为悬浮胶囊；窄屏固定在底部工具 dock 上方，可横向滚动。

### 4.4 右侧图层与属性

- 桌面端：桌面右侧竖排把手（宽 44px，图标 + 竖排文字「图层与属性」），点击展开 312px 浮层。
- 默认收起，浮层内滚动，不改变画布尺寸。
- 内容顺序（贴合概念图）：
  1. 图层顺序：置顶 / 上移 / 下移 / 置底 四宫格按钮；
  2. 旋转：滑杆 + 角度数字框（-180°–180°）；
  3. 缩放：滑杆 + 百分比数字框（20%–300%，以该类素材默认插入尺寸为 100%）；
  4. 文字格式（仅文字）：文字内容、字号、文字颜色、对齐、粗体、斜体；
  5. 删除按钮；
  6. 图层列表：全部元素，**顶层在前**，带缩略图与序号，点击即选中；未选中时面板显示引导文案。
- 选中文字时属性面板自动展开；照片/贴纸不自动展开，避免遮挡纸面。

### 4.5 顶部

- 不改造内页 header 与 BookShell toolbar，保留城市、可编辑标题、Journal/Collage 模式切换、保存状态与素材入口。
- 保存状态仍由 toolbar 的 `SaveStatus` 统一呈现，不在纸面上另做状态条。

## 5. 交互与无障碍

- 所有浮层互斥（左侧素材面板与右侧属性面板同时最多开一个）。
- `Esc` 收起当前浮层；关闭按钮有明确 `aria-label`（收起素材面板 / 收起图层与属性）。
- 素材按钮有 `aria-expanded`；浮动工具条按钮有可读名称与 `title`。
- 图层列表使用 `role="listbox"` + `role="option"`，`aria-selected` 标出当前元素。
- 触控目标不小于 32px；移动端主要操作集中在底部。

## 6. 响应式

| 断点 | 行为 |
| --- | --- |
| ≥ 1081px | 左侧工具轨 + 右侧把手浮在桌面两侧；纸张居中 |
| 861–1080px | 工具轨变窄、面板宽度收至 268px；纸张按高度公式收缩 |
| ≤ 860px | 左侧工具轨变为底部胶囊 dock；左右面板变为底部抽屉（互斥）；浮动工具条固定在 dock 上方 |
| ≤ 560px | 纸面左右留白 8px，纸张接近全宽；模式切换、保存状态按现有 BookShell 规则折行 |

移动端右侧把手改为纸面右上角圆形按钮；选中元素后浮动工具条出现，把手淡出避免重叠。短横屏手机（如 `667×375`、`568×320`）为纸面保留至少 `320px`（`≤ 560px` 时 `280px`）最小宽度并允许页面纵向滚动，避免按高度扣减后画布过小或消失。

## 7. 与概念图的差异（正式实现）

1. **顶部导航与外壳**：概念图是暖色羊皮纸头部；初版沿用深青地图 header 与半透明深青 toolbar，导致与浅棕桌面割裂且压缩了纸面面积。本轮通过 `InnerPageLayout` 的 `variant="collage"` 与 `BookShell` 的 `data-mode="collage"` 局部切换为紧凑暖色羊皮纸导航与皮革切换胶囊（仅作用于 Collage 页面，Journal 及其他内页维持深青航海样式不变）。
2. **面板默认态**：概念图左右面板都是展开的；实现按任务要求默认收起，点击展开，且浮层不挤压画布。
3. **右侧面板内容**：概念图有透明度滑杆、图层拖拽排序、隐藏图层；本轮不实现（非 V1-08 规划），保留旋转、缩放、图层顺序按钮与图层列表。
4. **撤销 / 重做**：概念图顶部有撤销重做；本轮不实现（任务明确非必做项），浮动工具条因此不含这两颗按钮。
5. **左侧素材库**：概念图把照片、城市贴纸、通用贴纸全部展开平铺；实现里一次只展开一个工具，并提供「打开素材册」跳到共享 `AssetPanel`，避免重复实现素材系统。
6. **城市贴纸 / 通用贴纸**：概念图是两组独立素材；实现从现有静态素材目录按 `cityId` 拆分为「本城市」与「通用」两栏，并通过 `collageStickers.ts` 仅在 Collage 模式下为「通用贴纸」补充 5 枚透明装饰贴纸（格子纸胶带、手账撕纸便签、复古旅行票根、手绘地图碎片、银杏叶贴纸），不新增素材系统，也不改变 Journal 的既有 34 张贴纸目录。
7. **纸面示例内容**：概念图的照片、标题、票根、地图、便签均不预置，初始为空白纸面。
8. **保存状态**：概念图在左下角显示「已自动保存」；实现由 BookShell 的 `SaveStatus` 统一显示，保留失败重试与冲突提示。
9. **纸张形态与材质**：使用独立生成的复古桌面底纹（`collage-desk.jpg`）、手工牛皮/棉纸纹理（`collage-paper.jpg`）、做旧牛皮封皮与黄铜包角（`collage-cover.png`）、做旧黄铜长尾夹（`collage-clip.png`）及手撕毛边轮廓遮罩（`collage-paper-mask.png`），不把概念图作为贴图。
10. **标题**：概念图在纸面上印有「南京 · 夏日回忆」；实现把书名保留在 BookShell 标题栏，纸面保持干净，便于自由拼贴。

## 8. 本轮不做

- 撤销 / 重做、透明度、图层隐藏、图层拖拽排序；
- 数据库 Schema、`CollageCanvas` / `CollageItem` 数据契约变更；
- 素材系统、保存队列、冲突保护、页面路由的重写；
- 对 Journal 日记本及其他页面的视觉改动。

实现阶段补充的细节（与概念图一致的方向）：

1. 照片在画布内带白色相纸边框与投影（`CollageStage` 的 `CanvasAsset` 以 `frame = max(6, min(width, height) * 0.045)` 绘制），贴纸带有柔和纸面投影，选中框采用陶土色圆角锚点，更接近贴上去的旅行手账质感。
2. 新建文字默认使用楷体栈 `KaiTi, STKaiti, "Kaiti SC", serif`，贴近手账手写感；文字行高 1.3。
3. 属性面板整体紧凑排版并使用细窄暖色滚动条，确保 1440×900 视口下选中文字时仍可同时看到格式控制与图层列表。
4. 移动端底部浮层打开时收起工具 dock，避免两排浮层叠在一起，并留足纸面底部与浮动工具条间距。
